DigitalOcean Setup

  1. Create Droplet at DigitalOcean.com
  2. Choose Ubuntu 22.04 LTS
  3. SSH into your droplet
  4. Run commands below:
curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh sudo usermod -aG docker $USER git clone https://github.com/Jhonlarry1010/swingview.git cd swingview docker-compose up -d

Access at: http://YOUR_DROPLET_IP:8443

AWS EC2 Setup

  1. Launch EC2 instance (t2.micro - free tier)
  2. Choose Ubuntu 22.04 LTS
  3. Assign Elastic IP for static access
  4. Configure Security Groups (allow ports 22, 8443, 5000)
  5. SSH and run same Docker commands as DigitalOcean
# After SSH into your EC2 instance curl -fsSL https://get.docker.com | sh git clone https://github.com/Jhonlarry1010/swingview.git cd swingview docker-compose up -d

Railway.app Setup

  1. Sign up at Railway.app
  2. Click "New Project" → "Deploy from GitHub repo"
  3. Authorize and select swingview
  4. Add environment variable: CODE_SERVER_PASSWORD=your_password
  5. Deploy automatically

Railway auto-detects Dockerfile and builds your app in seconds!

GitHub Codespaces Setup

Easiest option - no setup required!

  1. Go to your GitHub repo: github.com/Jhonlarry1010/swingview
  2. Click Code → Codespaces → Create codespace on main
  3. Wait 30 seconds for VS Code to load
  4. Start coding in browser!

Free: 60 hours/month included with free GitHub account

🔒 Security Checklist

  • Change default CODE_SERVER_PASSWORD to something strong
  • Use HTTPS with SSL certificate for production
  • Set firewall rules to limit who can access port 8443
  • Keep Docker images updated: docker-compose pull
  • Never commit .env file to GitHub
  • Use GitHub Secrets for sensitive data
  • Monitor your cloud resources and bills
